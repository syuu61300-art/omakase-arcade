# おまかせゲーセン

ジャンルがすべて違う **100本のミニゲーム** が、ランダムな順番で次々に始まるブラウザゲームです。
1本は30〜60秒。結果画面は3秒で自動的に次のゲームへ進みます。

- スマホ（タッチ・2本指同時押し対応）とPC（マウス・キーボード）の両方で遊べます
- インストール不要。ビルドも不要で、ファイルを置くだけで動きます
- 自己ベストはブラウザに保存されます

## 遊び方

| 操作 | スマホ | PC |
|---|---|---|
| スタート・次へ | タップ | クリック / スペース |
| ゲームを飛ばす | 左上の「スキップ」 | 左上の「スキップ」 |
| 一時停止 | 別のアプリに切り替えると自動で止まる | P キー |
| 音のオン・オフ | タイトル画面下のボタン | タイトル画面下のボタン |

各ゲームの操作方法は、始まる前の説明カードに表示されます。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例: `omakase-arcade`、Public）
2. このフォルダの中身をすべてアップロードする
   - ブラウザなら「Add file」→「Upload files」に、`index.html`・`js` フォルダ・`README.md` などをまとめてドラッグ
3. リポジトリの「Settings」→「Pages」を開く
4. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main** / **/(root)** にして「Save」
5. 1〜2分待つと `https://ユーザー名.github.io/omakase-arcade/` で遊べるようになります

コマンドで行う場合:

```bash
cd omakase-arcade
git init
git add .
git commit -m "おまかせゲーセン 100本版"
git branch -M main
git remote add origin https://github.com/ユーザー名/omakase-arcade.git
git push -u origin main
```

> `index.html` を直接ダブルクリックしても遊べます。

## ゲームを追加するには

新しい `js/pack9.js` を作り、`MG.reg({...})` でゲームを登録して、`index.html` に `<script src="js/pack9.js"></script>` を1行足します。

```js
MG.reg({
  id: 'mygame',            // 他と重ならないID
  name: 'ゲーム名',
  genre: 'ジャンル名',      // 既存と同じジャンルは入れない方針
  color: '#ff6f59',         // 説明カードの色
  time: 40,                 // 制限時間（秒）
  goal: 300,                // 金メダルの点数
  howto: '1行目\n2行目',     // 説明
  init(g) { return { /* 状態 */ }; },
  update(s, g, dt) { /* g.I に入力、g.add(点数) で加点、g.over('理由') で終了 */ },
  draw(s, g, ctx) { /* 720×960 の画面に描く */ }
});
```
